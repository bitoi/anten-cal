Uniform Linear Array (ULA) Theory

A Uniform Linear Array (ULA) consists of N identical elements arranged along a straight line (usually the Z-axis), with equal spacing d.

1. Array Factor (AF): The normalized AF magnitude is given by:

$$ |AF| = \left| \frac{\sin\left(\frac{N\psi}{2}\right)}{N\sin\left(\frac{\psi}{2}\right)} \right| $$

Where \(\psi\) is the total phase difference between adjacent elements:

$$ \psi = k \cdot d \cos(\theta) + \beta \quad \left( \text{with wave number } k = \frac{2\pi}{\lambda} \right) $$

2. Beam Steering: To steer the main beam to a desired angle \(\theta_0\), the required excitation phase \(\beta\) is calculated automatically:

$$ \beta = -k \cdot d \cos(\theta_0) $$

3. Pattern Multiplication Principle: The total radiation pattern depends on both the array geometry and the individual antenna element type:

$$ E_{\text{total}}(\theta, \phi) = AF(\theta, \phi) \times EF(\theta, \phi) $$

4. The directivity D: The directivity of the array can be calculated as:

$$ D = \frac{4\pi}{\int_0^{2\pi} \int_0^\pi |AF(\theta)|^2 \sin(\theta) d\theta d\phi} $$

5. Beamwidths: For a ULA, the half-power beamwidth (HPBW) and first null beamwidth (FNBW) can be approximated based on the number of elements N and the element spacing d:

$$ HPBW \approx \frac{102}{N \cdot d/\lambda} \text{ (degrees)} $$ $$ FNBW \approx \frac{180}{N \cdot d/\lambda} \text{ (degrees)} $$

Uniform Planar Array (UPA) Theory

A planar array extends the linear concept into two dimensions (X-Y plane), providing the ability to steer the beam in 3D space (both elevation \(\theta\) and azimuth \(\phi\)).

1. Total Array Factor: Formed by multiplying the Array Factors of two orthogonal linear arrays:

$$ |AF_{UPA}| = |AF_x| \times |AF_y| = \left| \frac{\sin\left(\frac{N_x \psi_x}{2}\right)}{N_x\sin\left(\frac{\psi_x}{2}\right)} \right| \times \left| \frac{\sin\left(\frac{N_y \psi_y}{2}\right)}{N_y\sin\left(\frac{\psi_y}{2}\right)} \right| $$

2. Spatial Phase Components (\(\psi_x, \psi_y\)):

$$ \psi_x = k \cdot d_x \sin(\theta)\cos(\phi) + \beta_x $$ $$ \psi_y = k \cdot d_y \sin(\theta)\sin(\phi) + \beta_y $$

3. 3D Beam Steering: To aim the main beam at target coordinates \((\theta_0, \phi_0)\), the system computes the required phase shifts for both axes:

$$ \beta_x = -k \cdot d_x \sin(\theta_0)\cos(\phi_0) \quad ; \quad \beta_y = -k \cdot d_y \sin(\theta_0)\sin(\phi_0) $$

4. Directivity Approximation: For a large planar array without grating lobes:

$$ D \approx 4\pi \left( N_x \frac{d_x}{\lambda} \right) \left( N_y \frac{d_y}{\lambda} \right) $$
